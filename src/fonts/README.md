# Fonts

Community recreations of the D&D 5e book typefaces by Solbera et al.,
licensed CC BY-SA 4.0 (see LICENSE). Source:
https://github.com/jonathonf/solbera-dnd-fonts

- Bookinsanity (regular/bold/italic/bold-italic) — body text (recreation of Bookmania)
- Mr Eaves Small Caps — headings (recreation of Mr Eaves Small Caps)
- Nodesto Caps Condensed — wordmark / hero titles (recreation of the cover-logo face)

Converted OTF -> WOFF2 with fonttools. Loaded via next/font/local in src/app/layout.tsx.
